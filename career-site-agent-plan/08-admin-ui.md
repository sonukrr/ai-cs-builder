# Company Admin Interface

## Product Name
Career Site Studio

## UX Principle
Do not build a chatbot-only experience.

Use:
- Conversational AI for intent
- Visual editing for context
- Structured controls for predictable actions
- Live preview for confidence

## Screen 1: Starting Point

Two primary cards:

### Import Existing Figma
"Bring your existing career site design."

### Start From Base
"Customize an approved career site foundation."

## Screen 2: AI Site Plan

Show:

```text
Homepage
✓ Hero
✓ Job Search
✓ Employee Stories
✓ Benefits

Jobs
✓ Job Listing
✓ Filters
✓ Pagination
```

Actions:
- Approve & Build
- Edit Plan

## Screen 3: Career Site Studio

Three panels:

### Left: Site Structure
Pages and sections.

### Center: AI Assistant
Conversation and suggested actions.

### Right: Live Preview
Desktop/tablet/mobile preview.

## Click-to-Edit
Selecting a preview section should automatically provide context:

```text
Editing:
Home → Hero Section
```

## Suggested Actions
- Improve Design
- Change Image
- Edit Content
- Adjust Layout
- Add Functionality

## Functional Component Catalog
Expose friendly options such as:
- Search Jobs
- Browse Jobs
- Apply for a Job
- Upload Resume

Do not expose internal implementation names.

## Additional Features
- Change summary
- Undo
- Version history
- Agent activity timeline
- Request Publishing
